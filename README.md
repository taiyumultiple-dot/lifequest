# 五門・心靈迷宮

生命教育互動推理遊戲。改編自泰宇生命教育教材的章首動畫腳本（總說＋第一單元 哲學思考）。

---

## 怎麼玩

可華掉進一座「心靈迷宮」，裡面矗立著五扇高聳的大門。要穿過這五扇門，他才回得了家。

每一扇門的核心玩法是**鑄鑰匙**：畫面上有九塊「思考碎片」，每一塊是一句話；
玩家要把它們排成正確的順序，鑄出開門的鑰匙。

- **齒紋吻合** ＝ 這塊碎片放對位置
- **有這道刻痕，但位置不對** ＝ 這塊碎片有用，但順序錯了

規則和經典的 1A2B 一樣，但排的不是數字，是**一條論證的邏輯順序**。
例如第一扇門的正解，就是可華反駁「幸福教教主」的那段話：

> 我總是想太多 → 但也因為這樣，我完成了很多好事 → 思想確實帶來痛苦
> → 可是事情不能只看一邊 → 思想也帶來了美麗和奇蹟 → 因為有人願意多想，人類才走到今天

### 六個關卡

| 關卡 | 標題 | 核心素養 |
|---|---|---|
| 序章 | 凝視生命的地圖 | 總說 |
| 第一扇門 | 我思故我在 | 哲學思考 |
| 第二扇門 | 鏡子裡的陌生人 | 人學探索 |
| 第三扇門 | 說再見之前 | 終極關懷 |
| 第四扇門 | 兩邊都有道理的時候 | 價值思辨 |
| 第五扇門 | 回到自己 | 靈性修養與人格統整 |

> 第二～五扇門目前是**暫定內容**。正式腳本到位後，只要替換內容即可，程式不用動。

### 其他系統

- **每日思辨**：每天一個生活情境，全世界同一天拿到同一題；連續七天可額外拿獎勵。
- **迷障圖鑑**：收集破解過的思考陷阱（以偏概全、訴諸群眾、非黑即白……），
  可裝備成「警覺」提供加成。
- **成長紀錄**：每一關結束會問一個反思題，答案只存在本機，可匯出成可列印的 HTML。
- **遊戲說明**：分五個分頁（故事／怎麼玩／數值／系統／給老師），含鑄鑰規則的圖解範例。
  第一次開遊戲會自動跳一次，之後可從「五扇門 → 怎麼玩」、「設定 → 遊戲說明」，
  或鑄鑰畫面右上角的「?」打開。**在鑄鑰途中打開說明時，倒數會暫停。**

## 怎麼打開

**最簡單**：直接雙擊 `index.html`。

**要測試 PWA（安裝成 App、離線遊玩）**：需要透過 http 開啟，例如在這個資料夾底下執行

```bash
python -m http.server 8811
```

然後開 <http://localhost:8811>。

**要上線**：整個資料夾丟到 Netlify 或 GitHub Pages 就好，沒有任何建置步驟。

## 怎麼改內容

### 方法一：直接改檔案（推薦）

打開 `js/data/units.js`，裡面六個關卡的文字都可以直接改，檔案開頭有完整的欄位說明。
改完存檔，重新整理網頁就生效。

其他可以改的資料檔：

| 檔案 | 內容 |
|---|---|
| `js/data/units.js` | 六個關卡的劇情、思考碎片、正解、反思題 |
| `js/data/daily-sets.js` | 每日思辨題庫（加越多，重複間隔越長） |
| `js/data/illusions.js` | 迷障圖鑑 |
| `js/data/characters.js` | 角色介紹 |
| `js/data/shop-items.js` | 補給站商品 |
| `js/data/titles.js` | 稱號 |
| `css/tokens.css` | 全站配色與字級 |

> 改完如果網頁沒更新，把 `index.html` 裡的 `?v=1` 改成 `?v=2`（瀏覽器快取用的版本號）。

### 方法二：載入內容包

在遊戲裡的「設定 → 載入內容包」，可以上傳一份 JSON 或直接貼上，
用它覆蓋六個關卡。格式就是 `units.js` 裡 `LQ.data.units` 那個陣列。
按「還原成內建內容」就會回到程式內建的版本。

## 素材處理工具

原始素材（角色立繪、分鏡圖）放在專案外面，用這兩支腳本轉成網頁能用的檔案：

```bash
python tools/cutout_characters.py
```
把六位角色的白底立繪去背，輸出到 `assets/characters/`。
用的是「從畫布邊緣往內漫延」的作法，所以白襯衫不會被一起挖掉。

```bash
python tools/build_assets.py
```
依 `tools/art_manifest.json` 的清單，從分鏡素材挑圖、縮到 1280px 寬、轉成 JPEG，
輸出到 `assets/scenes/`。要換圖就改那份 JSON。

```bash
python tools/contact_sheet.py <資料夾> <輸出.png> [起始編號] [張數]
```
把一堆分鏡圖拼成一張聯絡表，方便一次看完並挑圖。

三支腳本都會**跳過已經產好的檔案**，中斷可以直接重跑；
要重做某一張，把輸出的檔案刪掉再跑一次即可。

## 資料與隱私

- 全部資料存在瀏覽器的 `localStorage`（鍵：`lifequest_save_v1`），**不需要登入，不會上傳到任何地方**。
- 學生寫的反思內容也只存在自己的裝置上。
- 設定頁可以匯出／匯入存檔，或一鍵刪除全部資料。

## 安全提醒

第三扇門「說再見之前」會談到死亡與失去（`sensitive: true`）。
標記為 sensitive 的關卡，結算畫面會固定顯示求助資源：

> 安心專線 **1925**（24 小時）｜生命線 **1995**｜張老師 **1980**

設定頁也常駐「需要幫忙的時候」入口。新增會碰到這類議題的關卡時，
記得把 `sensitive` 設成 `true`。

## 技術

純 HTML / CSS / JavaScript，**沒有任何建置步驟、沒有任何外部套件**。
